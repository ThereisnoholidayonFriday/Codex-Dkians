# Twin Stars 内置审美控制（静态商业视觉）

本页是 Max 与 Pro 的共享决策准则。用户只需调用所选 Agent，不必另行调用 Taste。借鉴 Leonxlnx/taste-skill 的反模板、先读需求再选语言、成品预检等可迁移思路；不复制网页前端的 CSS、响应式、动效与交互规则，也不把第三方 Skill 当作静态图的必需运行依赖。此处的静态图控制量不是原 Taste 的原生参数。

## 1. 先作方向解读，再产出

用一句话写明：面向谁、用于什么渠道/画幅、表达什么卖点或情绪、品牌属于哪类视觉语言。区分四种参考角色：产品事实（外形/规格不可变）、品牌硬规则（Logo/字体/色值/禁区）、正向审美锚点（借用哪一处构图或质感）、反例（具体避免哪一处）。参考的角色不明时不要整体照搬。按「产品与确切文案 > 品牌硬规则 > 已批准方向 > 可调整偏好」处理冲突；涉及用户明确优先级则以用户明确要求为准。

先给每个方向一句可验证的视觉假设，例如“在手机首屏中，真实材质与偏侧逆光先于长文案建立质感”；再把每个强形容词转成画面可见特征。精确色值、Logo 净空、逐字文案、指定字体属于硬约束，不能以“审美优化”取消。

## 2. 方向质量锁：可对话覆盖，不要求 JSON

根据任务设置以下控制项，不机械全填。不知道时由 Agent 提议合理取值并说明；范围 1–10 仅表示本项目期望强弱，**不是审美得分**，同时必须写可观察目标。

| 控制项 | 1–3 | 4–7 | 8–10 | 必须随值给出的具体目标 |
| --- | --- | --- | --- | --- |
| 构图变化度 | 稳定规则、对称或清晰网格 | 分区、错位、尺度对比 | 非对称、显著尺度与留白变化 | 主体位置/占比、负空间位置、安全区、跨图变化点 |
| 视觉张力度 | 柔和低对比 | 受控明暗、方向感 | 强对比/戏剧光或强视觉冲击 | 焦点顺序、光源方向、亮暗比例、材质与色彩边界 |
| 信息密度 | 单重点、足量留白 | 多层信息但主次清楚 | 多项紧凑组织 | 字数、每屏层级、字号/可读性、不得删减的文本 |

不要仅凭数值判断通过。每张图另定镜头/表现方式、灯光与材料、色彩及字体、文案密度、产品/人物关系、禁用模式。对真实图片在目标画幅及预期展示尺寸下看图，先检硬约束，再检焦点、层级、辨识度和反模板性。

## 3. 方向差异和反模板

三个方向应至少在核心叙事与视觉组织上有实质差异，通常再改变视角/表现、证据方式、光线材质或图文关系；不能只换颜色、标题或装饰。不要自动套用紫色渐变、居中主体加三卡片、泛用玻璃拟态、空洞高级感或无关纹理。但如果这些正是有根据的品牌/参考要求，可以使用并说明理由。

“版式参考”只取其中明确指定的结构特征；“感觉像”应追问或提炼可观察的特征，而不是模仿来源标识。套图保持统一的字体、色彩与产品外观，但允许按资产目的变换镜头、距离、信息量和节奏；不要把整套图做成同构图换文案。

## 4. 样图预检与局部修图

样图选能检验方向难点的一张：真实产品、真实文案、目标尺寸/比例。按顺序检查：产品事实、文字和 Logo 硬约束；主视觉与信息焦点；小尺寸可读性；光影接触与材质真实感；品牌一致性；是否落入禁用模板。说清观察到什么、依据什么、结论是否限于该张样图。不要声称 Taste 单独审核、真实转化率提升或凭程序测试证明审美合格。

修图指令用“当前缺陷 → 目标变化 → 必须保留 → 禁改项目 → 复查点”表达。只修真实受影响资产，不用“更高级”代替改动。生成预算、审核与跳过规则仍按 Max/Pro 各自契约执行，不因审美控制增加隐形调用。

## 5. 可直接写给 Agent 的一句话

“只调用你这个 Agent 完成；先给方向解读和质量锁。构图变化度 6：主体偏左、右侧留白承载标题；视觉张力度 7：暖色侧逆光勾勒材质，不把产品打成黑色剪影；信息密度 5：主卖点一行、规格分组，手机尺寸下可读。保留产品结构、品牌紫色、指定字体和全部逐字中文文案；不要常见紫色渐变三卡片模板。样图按实际尺寸检查，不达标只改受影响部分。”
